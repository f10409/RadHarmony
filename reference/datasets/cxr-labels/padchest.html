    PadChest¶
    Registry keys padchest
    Task and outputs Classification, 193 labels (cls). The report text in Spanish (report)
    Images in the table 157,607 (66,587 patients, 107,439 studies). By default, the harmonizer drops the rows with exclude or suboptimal_study
    Modality Chest X-ray, 2-D, PNG
    License BIMCV PadChest research use agreement
    Download Get the data: PadChest

    PadChest is a chest X-ray dataset from Hospital San Juan de Alicante, Spain. BIMCV released it. Its 193 labels come from a text-mining tool on the Spanish reports, plus a manual review. The source CSV has 160,861 images of 67,625 patients.

    The source CSV also holds the report of each image. The reports are in Spanish. The authors cut each word to its stem, for example hallazg for hallazgo.

    Download each numbered zip by itself, because the zip of the whole folder does not resume. Unzip N.zip into images/N/.

    Quick use¶

    base_image_dir is the images/ folder. The class finds the label CSV in this folder or in the folder above it. The PNG files are in 52 folders: 0/ to 50/, and 54/.

    PadChest/
  PADCHEST_chest_x_ray_images_labels_160K_01.02.19.csv.gz
  images/
    0/20536686640136348236148679891455886468_k6ga29.png
    1/
    ...
    50/
    54/

    import torch
from radharmony.dataset import PadChestDataset

ds = PadChestDataset(
    base_image_dir="/data/PadChest/images/",
    output_cls=True,
    output_report=True,
    dtype=torch.float32,
)
train_ds, val_ds = ds.get_datasets(n_splits=5)  # 1/5 of the patients go to val
sample = train_ds[0]
# sample["img"]: Tensor(1, 224, 224)
# sample["cls"]: Tensor(193,)
# sample["report"]: ' sin hallazg patolog edad pacient .'

    How it is harmonized¶

    • Source: PADCHEST_chest_x_ray_images_labels_160K_01.02.19.csv.gz (or .csv). One row is one image (D-03).
    • IDs: patient_id is PatientID, for example 839860488694292331637988235681460987. study_id is StudyID, for example 20536686640136348236148679891455886468 (D-01). image_path is <ImageDir>/<ImageID>, for example 0/20536686640136348236148679891455886468_k6ga29.png. It is relative to base_image_dir (D-04).
    • Labels (193 columns, D-05): Labels holds a Python list as text, for example ['cardiomegaly', 'pleural effusion']. A label in the list gives 1, and all other labels give 0. The harmonizer removes a space at the start of a label, so ' pneumonia' and 'pneumonia' give one column. A row with the value [''] gets NaN in all 193 labels, not 0. The probes skip NaN.
    • Uncertain: PadChest has no -1. Two labels mark bad images: exclude and suboptimal_study. With drop_uncertain=True (the default), the harmonizer drops the rows with either label.
    • View (D-01): from Projection. L gives LATERAL, and AP_horizontal gives AP_HORIZONTAL. EXCLUDE and UNK give NaN. COSTAL stays.
    • Age and sex: the source has no age. age_years comes from the year of StudyDate_DICOM minus PatientBirth, in years (D-06). sex is M, F or NaN, from PatientSex_DICOM. The value O gives NaN (D-26).
    • Report: report is the Report column. With output_report=True, the dataset drops the rows with no report, and warns (D-33).
    • Dropped rows: the harmonizer always drops the 103 rows with a blank Labels value. It also drops a row whose Labels value is not a valid Python list.

    Splits¶

    Class Registry key Images Source
    PadChestDataset padchest 157,607 All images of the source CSV

    PadChest has no official split. get_datasets(n_splits=5) makes a train and val split. It groups by patient (D-10).

    Arguments¶

    Argument Type Required Default Description
    base_image_dir str Yes None The images/ folder with 0/ to 54/. Not needed with harmonizer_path, which holds it
    csv_path str No None The label CSV (.csv.gz or .csv). Without it, the class looks in base_image_dir and the folder above it
    drop_uncertain bool No True Drop the rows with the label exclude or suboptimal_study. With False, they stay

    Shared arguments (inherited from BaseRadiologicalDataset)¶

    Argument Type Required Default Description
    transform MONAI transform No None The image steps. None gives RadiologyTransform2D
    output_cls bool No False Add the cls tensor to the sample
    output_mask bool No False Not supported. The class warns and adds no key (D-11)
    output_report bool No False Add the report text to the sample. The class drops the rows with no report, and warns (D-33)
    output_reg bool No False Not supported. The class warns and adds no key (D-11)
    output_bbox bool No False Not supported. The class warns and adds no key (D-11). Localizations names regions, not boxes
    cache_dir str No "./cache" The MONAI cache folder. None gives no cache
    dtype torch.dtype No torch.bfloat16 The type of img. The labels stay float32
    harmonized_df pd.DataFrame No None A harmonized table to use
    harmonizer harmonizer No None A harmonizer to use
    harmonizer_path str No None A saved harmonizer. See Save and reuse a harmonized table

    Harmonizer¶

    from radharmony.harmonizer import PadChestHarmonizer

h = PadChestHarmonizer(
    csv_path="/data/PadChest/PADCHEST_chest_x_ray_images_labels_160K_01.02.19.csv.gz",
    base_image_dir="/data/PadChest/images/",
)
df = h.harmonize()  # harmonize() takes drop_uncertain, as the dataset does
print(df.columns.tolist())
# ['patient_id', 'study_id', 'image_path', 'view_position', 'report', 'age_years', 'sex',
#  'abnormal_foreign_body', ..., 'volume_loss']

    harmonize(drop_uncertain=False) keeps the rows with exclude or suboptimal_study.

    Argument Type Required Default Description
    csv_path str Yes The label CSV (.csv.gz or .csv)
    base_image_dir str No None The images/ folder

    Known data problems¶

    • Empty label lists: 777 rows have the Labels value ['']. Their reports name findings such as scoliosis, so an empty list does not mean normal (D-05).
    • Shared study ID: 1 StudyID belongs to 2 patients. The harmonizer warns. Group by patient_id and study_id together (D-01).
    • Age: the source has only the birth year, not the birth date. So an age can be 1 year too high. 6 rows have no birth year (D-06).
    • No report: 17 images of the default harmonized table have a blank Report (D-33).
    • Image folders: the folders 51/, 52/ and 53/ do not exist, and folder 50/ holds 1 image. This is the layout of the source, not a download error.
